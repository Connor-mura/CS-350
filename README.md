# CS-350

Summarize the project and what problem it was solving.

The goal of this project was to build and test a prototype for a smart home thermostat. I used a Raspberry Pi 4 breadboard setup with a built-in temperature sensor, LCD Display, LEDs, and user-friendly buttons. The prototype is meant to imitate the function of a smart home thermostat, where the system will blink either the blue or red LED when the temperature in the room is above/below the setpoint temperature and hold solid otherwise; a real system would adjust the temperature in the house instead of blinking an LED. This prototype establishes and tests the system code required to manage the automatic adjustments of a smart home thermostat.

What did you do particularly well?

I believe I did a good job writing my code and meeting the requirements of the assignment. Getting the code to run successfully was a process, as I spent a large amount of time debugging. In the end, I was able to fix the issues and get the system to run properly.

Where could you improve?

I could improve my time management skills; I turned this project in late because I underestimated the time it took to get the code to run successfully. Next time I will plan for setbacks and long debugging sessions to ensure I meet project deadlines.

Learning how to setup and work with the Raspberry Pi is also sets me up for success in the future, as these single board computers are excellent for both personal projects and production level designs.
